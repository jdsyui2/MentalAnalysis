# PIT Human Gold 标注与验收流程

基线：`12439cdab9f83c68b2586e59af9890db792aea13`（v3.2.2）。冻结模型 schema、问题和特征规则。本阶段只准备人工数据，不发布新工程版本、不调用模型、不生成自动 Gold。原 200 条 RETROSPECTIVE 标注包继续保留，不能代替 PIT 验收。

## 本轮采样

- PIT 协同：787 条正规语料中按当时的 PIT 特征排序取 100 条高信号候选，再从剩余记录随机取 100 条。50 DEV / 150 FROZEN。
- 方向：按平台随机取 300 条，东方财富 180、淘股吧 100、雪球 20。90 DEV / 210 FROZEN（各平台 30% 开发）。雪球仅 20 条，不能过度解释平台指标。
- 同平台、相似度 0.9 的近重复连通簇不能跨开发／冻结集。全批次近重复分组仅用于划分集合，不能出现在 PIT 标注证据里。
- 每项任务从 FROZEN 随机选 50 条双人独立标注。标注包本地保存，不上传原文或身份明细。
- 高信号层只是证据排序候选，不是真正协同标签。报告高信号、随机和总体指标；该富集样本总体比例不能估计自然协同发生率。随机层来自排除高信号后的剩余池，估计全语料比例还需两层抽样权重。

## 如何标注

打开任务目录 `annotate.html`，填写实际标注员标识，默认从 DEVELOPMENT 开始。选择标签并写明依据，保存后导出本人 JSONL。页面刷新会丢失未导出的记录；可导入本人结果继续。双人标注员独立操作，不查看彼此答案或模型预测。

### PIT 协同（闭集三标签）

- `NO_COORDINATION_EVIDENCE`：截至当时，已有足够观测支持未发现协同证据；不证明真人身份。
- `SUSPECTED_COORDINATED`：多项可观测证据支持怀疑群体协调发布；负面、简短、公告复制或常用金融词相似本身不够。
- `INSUFFICIENT_EVIDENCE`：作者、样本历史或证据不足，或证据冲突。

页面只展示当前评论、匿名作者和截至其 `available_at` 已可见的近重复成员及行为特征。任何晚于截止时间的记录都不得参与判断。样本来自有限语料，不代表平台全部历史。

### 方向（闭集五标签）

- `BULLISH`：作者明确表达目标证券价格／回报上涨判断。
- `BEARISH`：作者明确表达下跌判断。
- `NEUTRAL`：明确表达震荡、平衡或横盘判断。
- `UNCLEAR`：目标价格方向问题、歧义、反讽无法确定或不同期限冲突。
- `NOT_APPLICABLE`：纯事实、公告、无目标方向、无关内容或噪声。

按记录证券绑定识别目标；板块背景不自动等于明确主体。多标的无法归属需在依据中说明。不要把公告事件的利好猜测当作评论者的价格观点。

## 完成人工标签后的顺序

1. 人工核对样本与正文哈希，实际标注员和完成状态；保留两份独立标注，不用模型消除人类分歧。
2. 双人子集计算 Cohen κ、混淆表、标签支持数与一致率；争议由人工裁决并留下记录。当前无标签，所有一致性指标为空。
3. DEV 误差分析；仅 DEV 调问题／阈值，并拟合 temperature scaling。PIT 协同 DEV 50，方向 DEV 90；不要把协同开发样本数量误用于方向任务。
4. 锁定问题、参数、校准器和文件哈希，再一次性评测 FROZEN。看到冻结误差后调参则必须更换冻结集。
5. Choice 概率可以校准；启发式 `coordination_score` 仍是 `EXPERIMENTAL_HEURISTIC_NOT_CALIBRATED_PROBABILITY`，不改名为真实协调概率。

## 冻结验收门槛

方向：Bull/Bear precision ≥0.90、recall ≥0.80；NOT_APPLICABLE precision ≥0.95；macro-F1 ≥0.85；ECE <0.10。

协同：SUSPECTED_COORDINATED precision ≥0.90、recall ≥0.70。

报告各类支持数、未知率、覆盖率、混淆矩阵、Brier、ECE、bootstrap 95% CI及分层指标。缺类或缺标签时不宣称通过。人工完成、校准与正式冻结评测前保持 `RESEARCH_ONLY / PENDING_HUMAN_ANNOTATION`，不进入 ASDC 投资信号验证。
