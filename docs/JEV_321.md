# v3.2.1：Coordination Evidence & PIT Calibration

本轮完成上下文字段适配、协同簇证据、PIT/事后双模式、新标签、200条待标注候选、结构抽取+Jev接口与并发。校准和人工精度验收尚未完成。现有v3.1主体抽取仍保留；未修改EquityCrawler冻结合同或接入ASDC运行。

## 输入与时间边界

SocialContextAdapter接受legacy字段及EquityCrawler的content、point_in_time、observation、securities。author_id_hash按平台与author_hash_key_id隔离，昵称不作稳定作者。published_at是事件时间，available_at是当时可用时间，两者不互相补造。

RETROSPECTIVE使用全批次；PIT_CAUSAL对每条记录只使用available_at不晚于其自身as-of的记录，事件时间也不得晚于as-of。缺少可用时间、缺少带时区的事件时间或事件时间晚于可用时间时拒绝。互动快照没有自己的观测时间或晚于as-of，则不进入PIT特征。未知profile数据不进入PIT。

`require_asdc_context`拒绝事后模式及不通过PIT的特征，但这不是ASDC投资信号验收。模型输出、未来收益和采集覆盖的PIT验证仍待后续研究。本次104条legacy语料无available_at，不能补成PIT-ready。

## 协同证据

簇包含成员数、已知作者数、跨作者相似度、模板复用、发布时间跨度、平台及事后方向一致性。单条口号不构成协同证据。至少3条、3名稳定作者、高相似且15分钟内集中发布才生成实验性群体疑点；复制公告也可能是合法转载，疑点不是真实水军结论。

新标签：NO_COORDINATION_EVIDENCE / SUSPECTED_COORDINATED / INSUFFICIENT_EVIDENCE。旧配置及Gold保留原标签，不冒充新版本结果。新配置、新运行目录和新问题哈希分别记录。NO_COORDINATION_EVIDENCE不表示真人。

## Pipeline C

```sh
python -m scripts.jev_benchmark --config configs/jev_321.json \
  --output-dir local/jev_321_run --atomic-units path/to/validated_units.json
```

输入是已结构化原子单元：文本、cid、platform、atomic_units。每单元须有subject_code、subject_relation和可定位原文evidence。EXTERNAL/不同标的拒绝目标方向；UPSTREAM_DOWNSTREAM/UNKNOWN进入关系复核；PRIMARY且代码匹配、引文位置合法才调用Jev。完整原文保留给模型处理否定/条件，不把截断引文独立当成观点。抽取的模型立场不注入判断。

本次桥接已有本地规则提取的35个单元，不将它们称为经验证LLM抽取或生产Pipeline C。无单元评论不补造。A/C精度横评仍需Gold和可比预测。

## 并发和恢复

默认asyncio semaphore=4，两个问题层不互相输入winner。相同请求锁定，成功缓存按实际问题/上下文/配置隔离；认证或配额失败停止后续请求。每条结果与账本逐步保存，可恢复。返回模型版本、问题版本和hash均保留。
