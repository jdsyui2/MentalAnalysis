# JEV 3.2.2：PIT 接入收尾

冻结现有抽取与判断架构。本轮不新增模型调用，不填造人工 Gold。

## 时间规则

- `available_at` 必须是合法且带时区的时间；不从发布时间推算。
- `published_at=null` 合法，`publication_time_state=UNKNOWN`；非空非法时间失败；已知发布时间不得晚于该记录的可用时间。
- PIT 可见集合只包含截至当前 `available_at` 已可用且通过时间校验的记录。
- burst、作者 1h/24h 活动和簇时间集中度统一使用 `available_at`。原始发布时间保留作事件时间，RETROSPECTIVE 仍使用发布时间。
- 互动数据只有 `observed_at <= available_at` 才进入当时的特征。

## 输入成熟度

`LEGACY_NON_PIT` 表示缺少可验证时间；`CORPUS_PIT_CAPABLE` 表示具备时间能力；离线包完整性和逐记录时间校验全部通过时，包级检查输出 `CORPUS_PIT_VALIDATED`。此状态不证明作者真实、语义准确或投资信号有效。

## 真实接入验证

使用 EquityCrawler 0.2.3.1 的 `MentalExportManager` 从 canonical JSONL 重新导出 equity-social-corpus 1.0.0，不使用旧 104 条 legacy 输入，不改动生产者。

```sh
python -m scripts.corpus_pit_check --package LOCAL_PACKAGE --output LOCAL_SUMMARY
```

检查合同版本、文件 SHA-256、记录数和唯一身份，再检查全部记录的时间门禁；每平台前 10 条执行 PIT 特征及未来追加不变性验证（每平台最多 10 条）。不把抽样特征检查表述为全量语义分析。公开仅发布汇总，完整包保留于本地忽略目录。

测试中的便携合同记录使用合成正文与身份，结构来自正式导出合同；真实验证结果单独发布，不能把合成 fixture 当作真实数据评测。

Gold 和校准仍待人工工作，保持 `RESEARCH_ONLY / PENDING_HUMAN_ANNOTATION`；不升级投资信号或 ASDC 就绪状态。
